Из «Замечено без теста»: котировка старше 10 минут помечается в состоянии как устаревшая; блокировки сессий
удаляются после ответа; `/approach` ищется и относительно репозитория; стоимость учитывает скидку за кэш;
имя параметра лимита токенов и температура настраиваются (`LLM_MAX_TOKENS_PARAM`, `LLM_TEMPERATURE=none`);
eval-судью можно запустить на другой модели (`EVAL_JUDGE_MODEL`), проверка `quoted` понимает «1,150».
UI: ввод заблокирован до восстановления сессии; при 404 начинается новый диалог, введённый текст возвращается
в поле. XSS-проба, ширина 360 px и сброс счётчиков проверены в браузере.

Остаются решениями по дизайну (не код прототипа): фильтр заказов по `customer_id` и скрытие трассы инструментов
в API для реальных клиентов; поездка, найденная по номеру, подтверждается без вопроса (опечатка в номере даст
чужую поездку — оператор увидит маршрут в тикете); судья по умолчанию — та же модель, что и агент.

## Как запускать

```bash
uv run pytest qa -v                 # офлайн, фейковая модель, без затрат (~5–10 с)
uv run pytest qa -m crit            # только критичное; есть ещё -m major / -m minor
uv run pytest                       # основной набор tests/ не меняется и должен остаться зелёным
uv run python -m qa.live.run        # live: 14 враждебных сценариев на реальной модели (~$0.05 за прогон)
uv run python -m qa.live.run --runs 3
```

Live-отчёт пишется в `qa/live/runs/` (в git не попадает), `evals/report.md` не трогается.

## Замечено без теста (на решение)

- **Приватность по дизайну:** `OrderRepository.get(order_id)` / `search(date, time)` без id клиента. В проде любой, кто ввёл чужой номер или «вчера в 20:00», увидит маршрут, водителя, машину. API отдаёт клиенту трассу инструментов вместе с кандидатами-поездками.
- Поездка, найденная по номеру, подтверждается автоматически: опечатка в номере → тикет на чужую поездку и чужого водителя.
- Котировка «действует 10 минут», но в состоянии живёт вечно; модель может повторить её через час.
- `_locks` в оркестраторе не чистится: память растёт с каждой сессией (контейнер ограничен 256 МБ).
- Переносимость на OpenAI (README): `max_tokens` и `temperature=0.2` не принимаются reasoning-моделями; `prompt_cache_hit_tokens` есть только у DeepSeek. Счётчик стоимости не учитывает скидку за кэш.
- Evals: судья и симулятор — та же модель, что и агент (самооценка). 45/45 без единого враждебного сценария. Проверка `quoted` не видит «1,150».
- `/approach` ищет `docs/approach.html` относительно текущей папки: `taxi-agent serve` не из корня репо → 404.
